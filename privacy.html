Политика конфиденциальности Ivi

Обновлено: 12 ноября 2026 года.

Какие данные получает приложение

Ivi просит у Google только право drive.file: доступ к файлам, которые приложение создало само. Других файлов в Google Drive, почты, контактов и календаря приложение не видит.

Как они используются

Приложение загружает PDF-файлы владельца в его Google Drive и открывает их по ссылке для чтения, чтобы подписчики могли скачать гайд. Ничего другого с данными Google не делается.

Передача и хранение

Данные из Google не продаются, не передаются третьим лицам и не используются для рекламы или обучения моделей. Ключ доступа хранится только на сервере владельца и не публикуется.

Использование данных, полученных через API Google, соответствует Google API Services User Data Policy, включая требования Limited Use.

Как отозвать доступ

Доступ можно отозвать в любой момент на странице myaccount.google.com/permissions.

Контакты

Вопросы — по адресу поддержки, указанному на экране входа Google для приложения Ivi.

Privacy policy (English)

Ivi requests only the Google drive.file scope: access to files the app itself creates. It uploads the owner's PDF files to the owner's Google Drive and shares them with a view link. Google user data is not sold, not shared with third parties, and not used for advertising or model training. Ivi's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. Contact: the support email shown on Ivi's Google consent screen.
